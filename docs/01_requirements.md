# 要件定義

## プロジェクト概要

転職活動用GIS×AIエージェントポートフォリオ。GIS・インフラ系企業のPM/SE職応募に向け、
「GISを使う側のPMとして設計力・AI活用力がある」ことを示す。

## ユーザーストーリー

### トップページ
- 採用担当者として、ポートフォリオの概要と使用技術を一目で把握したい
- 採用担当者として、4つのデモアプリに直接アクセスしたい
- 採用担当者として、GitHubのソースコードと設計ドキュメントへのリンクを見たい

### /infra（設備管理マップ）
- ユーザーとして、地図上に設備アイコンを表示して位置を把握したい
- ユーザーとして、要点検・要修理の設備をフィルタして確認したい
- ユーザーとして、設備をクリックして詳細属性を確認・更新したい
- ユーザーとして、「梅田周辺の要点検設備を教えて」と自然言語で問い合わせたい

### /hazard（防災・避難所マップ）
- ユーザーとして、ハザードゾーン（洪水・土砂）をポリゴンで確認したい
- ユーザーとして、近くの避難所を地図上で確認したい
- ユーザーとして、「現在地から1km以内の避難所は？」と問い合わせたい

### /road（道路・交通マップ）
- ユーザーとして、通行止め・工事中区間を色分け表示で確認したい
- ユーザーとして、交通量をヒートマップで把握したい
- ユーザーとして、「通行止め区間を全て表示して」と問い合わせたい

### /estate（不動産物件管理マップ）
- ユーザーとして、地図上でポリゴンを描画して物件エリアを登録したい
- ユーザーとして、物件の名称・種別・価格・オーナー等の属性を登録・編集したい
- ユーザーとして、物件一覧テーブルと地図表示を連動させたい
- ユーザーとして、「梅田の商業物件を表示して」と問い合わせたい

## 機能要件

| ID | 機能 | 優先度 |
|----|------|--------|
| F01 | MapLibre GL JSによる地図表示（OSM） | 必須 |
| F02 | PostGISからGeoJSONを取得してレイヤー表示 | 必須 |
| F03 | AIチャットUIからMCPエージェントを呼び出し | 必須 |
| F04 | 設備・物件のクリックで属性パネル表示 | 必須 |
| F05 | ポリゴン描画（estate）・点データ登録（infra） | 必須 |
| F06 | 副作用操作の確認フロー（confirm_token） | 必須 |
| F07 | ループ検知・タイムアウト（max 10calls / 30s） | 必須 |
| F08 | AI停止時の地図機能継続（graceful degrade） | 必須 |
| F09 | request_idロギング | 必須 |
| F10 | 交通量ヒートマップ（road） | 推奨 |

## 非機能要件

| 項目 | 要件 |
|------|------|
| 可用性 | AI機能停止時も地図表示は継続 |
| セキュリティ | APIキーはブラウザ非公開・ジオメトリ検証必須 |
| パフォーマンス | 地図初期表示3秒以内 |
| ブラウザ | Chrome最新版・Safari最新版 |

## データソース

| アプリ | データ | ソース |
|--------|--------|--------|
| infra | 設備データ | 独自サンプルデータ（架空）|
| hazard | ハザードゾーン | 国土地理院ハザードマップポータル（GeoJSON） |
| hazard | 避難所 | 国土数値情報（公共施設）|
| road | 道路区間 | OpenStreetMap（OSMDB） |
| estate | 物件データ | ユーザー登録（デモ用） |
